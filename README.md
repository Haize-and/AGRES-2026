# AGRES 2026 - Undergraduate Research Symposium Website

This is the official website design for the Faculty of Agriculture, Wayamba University of Sri Lanka's Undergraduate Research Symposium (AGRES 2026).

## Technologies Used
- **HTML5**: Semantic structure.
- **Tailwind CSS (via CDN)**: Modern, utility-first styling for a premium "supiri" look.
- **Vanilla JavaScript**: For smooth scrolling, mobile navigation, and animations.
- **FontAwesome**: For icons.
- **Google Fonts**: Inter & Playfair Display for typography.

## How to Run
Simply double-click on `index.html` to open the website in your browser. No installation is required.

## Features
- **Responsive Design**: Works perfectly on mobile and desktop.
- **Modern UI**: Glassmorphism effects, gradients, and smooth scroll animations.
- **Multi-page Structure**:
  - `index.html`: Home page with Hero, Tracks, and Key Dates.
  - `about.html`: Information about the Faculty, Mission, and Vision.
  - `committee.html`: Organizing committee members with profile cards.
  - `contact.html`: Contact form and location map.

## Customization
- To change colors: Edit the `tailwind.config` script inside the `<head>` tag of each HTML file.
- To update images: Replace the `src` attributes of the `<img>` tags.
